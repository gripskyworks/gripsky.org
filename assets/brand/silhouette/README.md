# GripSky 单色轮廓标志

状态：2026-09-30 本地首页设计候选已获主体认可。用于后续界面与品牌规格开发；这套文件尚未替换网站现有 favicon、邮件头像、安装图标或组织结构化数据。

## 识别结构

保留原标志的大写 G 与中心三向结构。三条分支的末端各有一个圆点；在这套单色轮廓里，G 和中心块面是一种颜色，三向与末端圆点以镂空呈现。没有额外的方形色块、外发光或独立的中心球。

首页图板当前通过 [`BrandSilhouette.tsx`](../../../app/components/BrandSilhouette.tsx) 在 SVG 中从既有 [`gripsky-brand-mark-v1.png`](../../../public/gripsky-brand-mark-v1.png) 提取相同轮廓。原图未修改，SHA-256 为 `bb0cb87bf147097680d617d485208febd69882aa2b9e5a0dfa8701720f26e0c6`。这些导出图是便于复用的衍生件，不另立一个与原图竞争的结构正本。

## 导出规格

| 版本 | 颜色 | 背景 | 文件名前缀 |
| --- | --- | --- | --- |
| light | 暖白 `#F3EEE1` | 深青、暗轨等深色底 | `gripsky-silhouette-light` |
| ink | 深青 `#143F3B` | 暖纸、浅色玻璃等浅色底 | `gripsky-silhouette-ink` |

两版都是透明底。每版提供 `16、24、32、48、64、96、128、180、192、256、512px` 的正方形 PNG，以及一份可独立移动、内嵌蒙版的 512×512 SVG。大尺寸 PNG / SVG 可供后续继续缩放；SVG 内嵌了 512px 位图蒙版，**不应称作纯矢量描摹**。

导出画布按图形的实际边界收紧，四周约留标志外接方框 5% 的安全空间；只是裁切透明留白，没有改变 G、三向和三个端点的位置关系。浏览器里最小的 16px 可辨认 G，三向细节会受设备像素密度影响；需要表达完整结构时优先使用 32px 以上，展示图建议 64px 以上。触屏图标和搜索缩略图使用前还需结合目标平台测试背景、圆角裁切与实际像素尺寸。

[`preview.png`](preview.png) 并排展示两种配色与全部尺寸。预览图右侧的大规格为方便比较，显示尺寸统一压到 92px；标注数字是各文件的真实像素尺寸。

## 再生成和后续接入

在项目根目录运行 `npm run brand:generate`；[`generate-brand-silhouette.mjs`](../../../scripts/generate-brand-silhouette.mjs) 会先核对原图散列，再以与页面蒙版相同的红通道阈值提取轮廓，并覆盖本目录中的衍生文件。若原图将来正式换版，应先审视轮廓及配色，再更新脚本的来源和散列，不直接跳过校验。

将来用于 favicon、邮件、安装清单或结构化数据时，先选定各处背景和缓存版本名，并在实际缩略尺寸检查三向结构；随后同步更新代码引用、搜索/安装元数据和本规范。此步骤尚未执行。
